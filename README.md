# Telegram Bot: «Порфирий Пыхтин — укротитель катастроф»

Бот для приёма заявок на ремонт в апарт-отеле. Пошагово собирает данные: услуга → адрес → описание проблемы → временное окно — и присылает итоговое подтверждение.

## Как запустить

- Установите зависимости: `pip install pytelegrambotapi python-dotenv`
- Создайте файл `.env` и добавьте: `Bot_TOKEN=ваш_токен_от_BotFather`
- Запустите: `python Apart_HotelSea_bot.py`

## Команды

- `/start` — приветствие и список услуг
- `/electric` — вызов электрика
- `/plumber` — вызов сантехника
- `/cleaner` — вызов клининга
- `/time_9_12`, `/time_12_15`, `/time_15_18` — выбор временного окна

## Логика работы

`send_welcome` — приветствует пользователя и предлагает выбрать услугу → `choose_service` — получает выбранную услугу и сохраняет её данные → `get_apartment` — запрашивает и получает номер корпуса и квартиры → `get_explanation` — получает от пользователя описание проблемы → `choose_time` — предлагает выбрать удобное время для визита специалиста → после выбора времени заявка считается полностью заполненной.

## Использованные обработчики

### Использованные обработчики

- `@bot.message_handler(commands=['start'])` — обрабатывает команду `/start` и запускает приветствие пользователя.
- `@bot.message_handler(commands=['electric', 'plumber', 'cleaner'])` — обрабатывает команды выбора услуги: электрика, сантехника или услуги уборки.
- `bot.register_next_step_handler(message, get_apartment)` — переводит бота к следующему шагу и ожидает от пользователя номер корпуса и апратамента.
- `bot.register_next_step_handler(message, get_explanation)` — переводит бота к следующему шагу и ожидает описание проблемы.
- `@bot.message_handler(commands=['time_9_12', 'time_12_15', 'time_15_18'])` — обрабатывает команды выбора удобного времени для визита специалиста.

## Работа с AI

Проект разработан в связке Python + AI-инструменты: Алиса, ChatGPT и Perplexity. AI использовался для объяснения логики и цепочки вызовов в коде, а также помощи в отладке и поиске ошибок.

**Методы промптинга:**

- **One-Shot** — один пример для задания формата ответа
- **Chain-of-Thought (CoT)** — пошаговое рассуждение для логики и аналитики
- **Role Prompting** — назначение роли (Порфирий Пыхтин) для генерации текстов в едином стиле
